# 안전관리 도우미 (261004)

명령어 입력 없이 버튼만 눌러 쓰는 안전관리 파이썬 도구입니다.

## 기능
| 번호 | 기능 |
|---|---|
| ① | 위험성평가 위험도 자동계산 · 등급 색칠 · 개선 필요 목록 |
| ② | 점검기록(여러 엑셀) 하나로 합치기 + 요약 |
| ③ | 교육·검사·자격 만료일 알림 (D-day, 30·60일) |
| ④ | 내 PC 자료 키워드 검색 (PDF·엑셀·워드·한글·텍스트) |

## 사용 방법 (Windows)
1. 오른쪽 위 **Code → Download ZIP**으로 내려받아 압축을 풉니다.
2. `1_처음설치(setup).bat` 더블클릭 (처음 1회, 파이썬·라이브러리 설치)
3. `2_실행(run).bat` 더블클릭 → 프로그램 실행
4. 결과 파일은 프로그램 폴더 안 `결과` 폴더에 저장됩니다.

## 파일 구성
| 파일 | 설명 |
|---|---|
| `safety_helper.pyw` | 프로그램 본체 |
| `1_처음설치(setup).bat` | 라이브러리 설치 (pandas, openpyxl, pypdf, python-docx, olefile) |
| `2_실행(run).bat` | 실행 |
| `양식/위험성평가_양식.xlsx` | 위험성평가표 양식 (5×5 행렬, 예시 데이터) |
| `양식/만료관리_양식.xlsx` | 교육·검사·자격 만료 관리대장 양식 |
| `사용설명서.pdf` | 사용설명서 |

## 확인 필요
- 위험도 등급 기준(`GRADES`, 1~4 낮음 / 5~9 보통 / 10~14 높음 / 15~25 매우높음)은 **예시**입니다. 사업장 위험성평가 실시규정에 맞게 `safety_helper.pyw` 위쪽 설정 부분을 수정하세요.
- 만료관리 주기는 법정·사내 기준을 담당자가 확인해 입력하세요.
